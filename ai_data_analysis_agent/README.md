# 🐪 AI Data Analysis Agent (Google Gemini + DuckDB + Streamlit)

Agente de Inteligencia Artificial para analise conversacional de planilhas (CSV e Excel).

---

## Como Executar

1. Iniciar a aplicacao web:
   streamlit run ai_data_analysis_agent/app.py

2. Inserir sua Gemini API Key na barra lateral.
3. Carregar um arquivo .csv / .xlsx ou clicar em 'Usar Planilha de Exemplo'.
4. Digitar perguntas em linguagem natural.
